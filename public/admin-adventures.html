Idle Adventures admin is CLI-only

Pop-Up events, rarity and Style Luck overrides, and analytics are signed on the operator machine with npm run admin:adventures. This page does not accept a key, and the browser never signs admin requests. 

npm run admin:adventures -- analytics
npm run admin:adventures -- state
npm run admin:adventures -- popup-create --json payload.json
npm run admin:adventures -- popup-end --id summer-block-party
npm run admin:adventures -- override-rarity --json rarity.json
npm run admin:adventures -- override-luck --json luck.json

The CLI reads the local operator key file (default .dev.vars) and never prints it. Pass --origin if it must match the worker APP_ORIGIN. Use --help for the full flag list.
